# lotto

로또 6/45 번호를 만들어 주는 PowerShell 스크립트입니다.

## 규칙

- 1~45에서 중복 없이 6개를 뽑아 오름차순으로 출력
- 홀:짝 비율은 2:4, 3:3, 4:2만 허용
- 합계는 22~254 범위만 허용
- 3개 이상 연속된 번호는 제외
- 난수는 암호학적으로 안전한 난수 생성기(CSPRNG)로 뽑고, 모듈로 편향이 생기지 않게 처리

## 웹 버전 (휴대폰 지원)

`index.html` 한 파일로 된 정적 웹페이지입니다. 브라우저의 `crypto.getRandomValues`로 번호를 뽑고, 결과 복사·공유 기능이 있습니다.
Vercel에서 이 저장소를 Import하면 별도 설정 없이 배포됩니다.

## 사용법 (PowerShell)

```powershell
.\lotto.ps1            # 기본 5게임
.\lotto.ps1 -Games 10  # 10게임
```

실행 정책 때문에 막히면 다음처럼 실행하세요.

```powershell
powershell -ExecutionPolicy Bypass -File .\lotto.ps1
```

## 출력 예시

```
행운의 로또 번호 추천 결과입니다:
- 1게임: [ 12, 23, 32, 33, 39, 45 ] (홀4:짝2 / 합계: 184)
- 2게임: [ 3, 4, 9, 21, 30, 42 ] (홀3:짝3 / 합계: 109)
...
```

> 로또 당첨은 완전한 무작위 확률 게임이므로, 이 번호가 당첨을 보장하지 않습니다. 가볍고 재미로만 즐겨주세요!
